# FireCash – UI Stitch & Design Tokens Integration Plan

## Design System: Material Design 3 Dark Theme ("FireCash")

### Color Tokens
- **Background**: `#121316` (Deep Obsidian / Dark Charcoal)
- **Primary**: `#FF6B00` (Electric Amber / Fire Accent)
- **Primary Container**: `#FF6B00` / `#FF8A3D`
- **Secondary**: `#10B981` (Emerald Green - Verified Badges)
- **Tertiary**: `#6366F1` (Indigo Blue - Insights & Trends)
- **Surface**: `#1A1C20`
- **Surface Container High**: `#22252A`
- **Surface Container Highest**: `#2C3036`
- **Error**: `#EF4444` (Coral Red - Duplicates & Mismatches)

### Typography & Spacing
- **Monospace Numbers**: Used for financial amounts, CRC codes, and timestamps.
- **Card Spacing**: 8dp grid, rounded corners (`14dp` to `20dp` radius).
- **Test Tags**: Fully tagged interactive components for automated testing (`search_expenses_input`, `add_expense_fab`, `analytics_total_spent`, etc.).
