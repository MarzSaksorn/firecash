## 📱 2. คุณสมบัติที่มีในปัจจุบัน (Implemented Features)

### **หน้าหลัก (Account Screen)**
* **การแสดงยอดเงิน (Balance Card):** แสดงยอดเงินเข้า-ออก พร้อมปุ่มทางลัดสำหรับเปิดกล้องถ่ายรูป
* **สรุปการใช้จ่าย (Spending Summary):** มีปุ่มสำหรับดูภาพรวมการใช้จ่าย
* **รายการธุรกรรม (Transactions):** ระบบค้นหาธุรกรรมที่สามารถกรองข้อมูลได้, แสดงรายการแบบกลุ่มตามวันที่ (เรียงจากใหม่ไปเก่า) และแสดงยอดรวมสุทธิในแต่ละวัน
* **การจัดการรายการ (Management):** รองรับการกดค้างเพื่อเลือกหลายรายการ (Multi-select) และลบรายการที่ยังไม่ผ่านการยืนยัน หรือรายการที่ไม่มีเลขที่อ้างอิง

### **ระบบวิเคราะห์ข้อมูล (Analytics)**
* **บัตรสถิติ (Stat Cards):** แสดงข้อมูลสรุปตัวเลขสำคัญ
* **กราฟวงกลม (Donut Pie Chart):** แสดงสัดส่วนรายรับ-รายจ่ายรายเดือน พร้อมแสดงยอดเงินสุทธิ (Net) ไว้ตรงกลาง
* **โหมดเปรียบเทียบ (Compare Mode):** สามารถเปรียบเทียบข้อมูลรายเดือนได้ (สูงสุด 3 เดือน) โดยแบ่งสัดส่วนกราฟให้เห็นความแตกต่างชัดเจน

### **ระบบการตรวจสอบ (Verification)**
* **ผู้ให้บริการตรวจสอบ (Providers):** รองรับ 3 รายหลัก ได้แก่ EasySlip, ThunderAPI และ Slip2Go
* **การตั้งค่าการตรวจสอบ (Settings):** สามารถเลือกผู้ให้บริการผ่านหน้า Settings, ตั้งค่า API Key ของแต่ละราย และมีระบบสำรองข้อมูลกรณีใช้งานแบบออฟไลน์ (Offline Fallback)
* **การจัดการข้อผิดพลาด:** มีการจัดการ Error Code อย่างเป็นระบบ (เช่น 401, 404, 429)

### **การตั้งค่า (Settings)**
* **ส่วนปลอดภัย (Safe):** จัดการรายชื่อที่รู้จัก, โฟลเดอร์ที่ติดตาม, การตั้งค่า Keyword และโหมดส่วนตัว/ร้านค้า
* **ส่วนอันตราย (Dangerous):** การตั้งค่าการตรวจสอบสลิป, การตั้งค่า Whitelist การแจ้งเตือน, การตั้งค่าการทำงานเบื้องหลัง และการโอนย้ายข้อมูล
